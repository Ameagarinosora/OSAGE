# OSAGE
OSAGE is a macro library for AARCH64 GNU Assembly, or more like an eDSL. It adds functions, blocks, control flow, named variables, I/O with no compiler, all macro-based.

Features:
- Functions (fn)
- Named variables
- Console I/O (eg. stdout, stdin, putb)
- Conversion (float <-> str <-> int)
- Data Helpers (eg. string, buffer)
- Block Checking
